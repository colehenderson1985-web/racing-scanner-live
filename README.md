# Cole's Market Inefficiency Scanner — live page

Static page served by GitHub Pages, with two tabs:

- **Racing** — `snapshot.json`, pushed every couple of minutes by the scanner on Cole's laptop (ratings, odds, edges, speed maps, picks; no personal bankroll or bets).
- **NFL** — `nfl.json`, pushed when it changes (every few hours): anytime-touchdown model probabilities, game angles, calibration and Cole's paper picks. Type a bookie price on the page to see edge and a suggested stake; prices stay on your device.

Ratings and probabilities are shared for interest, not advice; the models are not proven against bookmaker prices.
