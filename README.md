# Cole's Racing Scanner — live page

Static page served by GitHub Pages. `snapshot.json` is pushed every couple of minutes
by the scanner running on Cole's laptop (ratings, odds, edges, speed maps, picks —
no personal bankroll or bets). The page polls it and re-renders.

Ratings come from an unvalidated model and are shared for interest, not advice.
